Questions about AI costs

How do I reduce AI API costs?

Use the smallest model that does the job well (small models can cost up to 100× less than the flagship from the same company), cache instructions that never change, send jobs that can wait to a batch API (50% off at Anthropic, Google, Mistral, OpenAI), keep prompts short, run bots only as often as things change, and set a spend limit before anything runs on autopilot.

What is the cheapest LLM API?

Of the models in our price table, the cheapest per token is Groq openai/gpt-oss-20b at $0.075 per 1M input tokens and $0.30 per 1M output tokens (official pricing page, checked Oct 21, 2026). Cheapest isn't always good enough: test it on your real job first.

How much does an AI agent cost to run?

It depends on how often it runs and how much it reads. Example: a morning inbox briefing that reads about 15,000 tokens and writes 800 on 22 weekdays a month costs about $0.03 a month on Groq openai/gpt-oss-20b, and about $4.18 on Anthropic Claude Fable 5.1, at standard API prices. Use the calculator on this page for your own numbers.

Is a monthly AI plan cheaper than paying per use?

If you run a few small bots, pay-per-use API prices are often a few dollars a month or less. App plans charge a flat monthly fee with usage limits, and include the app itself. Compare both before you commit: see our guide “Plan or pay-per-use: which is cheaper for you?” on this page.
