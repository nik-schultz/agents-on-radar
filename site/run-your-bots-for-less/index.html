Run your bots for less

Every time a bot runs, an AI service bills you, or eats into your plan's limits. These 8 guides show how to pay less for the same results, with prices taken only from the providers' official pages.

8 rules that cut your AI bill

  1. Use the smallest model that does the job well. How →
  2. Test on a free tier first, without private data. How →
  3. Check whether a flat monthly plan or pay-per-use is cheaper for you. How →
  4. Cache the parts of the prompt that never change, and batch what can wait. How →
  5. Run simple, private jobs on an open model on your own computer. How →
  6. Run bots only as often as things change, or only when you ask. How →
  7. Keep prompts, tools and pasted pages short. How →
  8. Set a spend limit before anything runs on autopilot. How →

The guides

  • 🪙 Run your bots for less

    Use a small model for simple jobs and save the big one for hard ones

    Most bot jobs (sorting email, summarizing, checking a page) don't need the most powerful model. The small models cost a fraction as much, so route easy work to them and only send hard problems up.

    Build and test your bot on a free tier before you pay

  • 🪙 Run your bots for less

    Decide between a monthly AI plan and paying per use

    A monthly plan (like Claude Pro) gives you a flat price with usage limits. Paying per use through an API costs exactly what you use. Which is cheaper depends on how much your bots run.

  • 🪙 Run your bots for less

    Cut your AI bill with prompt caching and batch discounts

    If your bot sends the same long instructions every time, caching makes the repeat part much cheaper. If results can wait a few hours, batch processing halves the price at several providers.

  • 🪙 Run your bots for less

    Run open models on your own computer (or a cheap host) for simple jobs

    Open-weight models can run on your own computer with a free tool like Ollama, so routine jobs cost nothing per message. Some hosts also run open models for a fraction of big-model prices.

  • 🪙 Run your bots for less

    Stop always-on bots from burning tokens: run them less often, or on demand

    Every scheduled run costs tokens, even when nothing has changed. Match the schedule to how often the thing really changes, and switch fun-but-idle bots to run only when you ask.

  • 🪙 Run your bots for less

    Keep your bot's prompts, tools and context short

    You pay for everything the model reads on every run: your instructions, tool definitions, pasted pages and the conversation so far. Trimming those is often the easiest saving.

    Set spend limits and usage alerts on your AI accounts

    Before a bot runs on autopilot, put a hard cap on what it can spend and check usage weekly, so a runaway loop can't run up a big bill.
