Discounts you can use

  • OpenAI: Batch API: 50% off, results within 24 hours (source, checked Oct 27, 2026)
  • OpenAI: 12-hour prompt caching (added Oct 20, 2026): keeps shared instructions cached for hours at the cached-input price; 12-hour cache writes cost 2.5x the input price (source, checked Oct 27, 2026)
  • Anthropic: Batch API: 50% off input and output. Prompt cache reads cost 0.1x the input price (0.05x on Opus/Sonnet 5.5, 0.025x on Fable 5.1); 5-minute cache writes cost 1.25x. (source, checked Oct 27, 2026)
  • Google: Batch API: 50% cost reduction (paid tier). Free tier: free input and output tokens on some models, and your content is used to improve Google's products. (source, checked Oct 27, 2026)
  • Mistral: Batch processing: 50% off. Cached input tokens: up to 90% off for repeated prompts. (source, checked Oct 27, 2026)
  • DeepSeek: Off-peak discount: prices are half outside peak hours (01:00-04:00 and 06:00-10:00 UTC on weekdays). Cache hits are far cheaper than misses. (source, checked Oct 27, 2026)

Questions about AI API prices

What is a token?

A token is a small chunk of text, a few characters long. AI APIs charge per million tokens, with one price for the tokens the model reads (input) and another for the tokens it writes (output). Every price in this table is per 1 million tokens.

What is the cheapest LLM API?

Of the models in our price table, the cheapest per token is Groq openai/gpt-oss-20b at $0.075 per 1M input tokens and $0.30 per 1M output tokens (official pricing page, checked Oct 27, 2026). Cheapest isn't always good enough: test it on your real job first.

What's the cheapest way to call an LLM API?

Use the smallest model that does the job well (use a small AI model for simple jobs, a big one for hard ones), keep prompts and pasted pages short (keep your bot's prompts, tools and context short), reuse the same opening instructions so they can be billed at the lower cached-input price where the provider offers it, and send jobs that can wait through a batch API (50% off at Anthropic, Google, Mistral, OpenAI; cut your AI bill with prompt caching and batch discounts). Test on a free tier first (build and test your bot on a free tier before you pay) and set a spend limit before anything runs on autopilot (set spend limits and usage alerts on your AI accounts).

What does “cached input” mean?

Some providers bill prompt text they have already cached, like instructions you send every time, at a lower rate. For example, OpenAI gpt-6-astra lists $10.00 per 1M input tokens and $1.00 per 1M cached input tokens on its official pricing page. The Cached input column shows this rate where the provider publishes one.

What is the cheapest AI API for each kind of job?

Cheapest per token overall: Groq openai/gpt-oss-20b, $0.075 / $0.30 per 1M input / output tokens. Cheapest small model from OpenAI, Anthropic, Google or xAI: OpenAI gpt-6-luna and Anthropic Claude Haiku 5.5, $0.10 / $0.50 per 1M input / output tokens. Cheapest model with a free tier: Google gemini-3.1-flash-lite, $0.25 / $1.50 per 1M input / output tokens. Cheapest mid-size model: Groq openai/gpt-oss-120b, $0.15 / $0.60 per 1M input / output tokens. Cheapest flagship model: xAI grok-4.7, $2.00 / $6.00 per 1M input / output tokens. With off-peak pricing, DeepSeek deepseek-flash (V4.1-Flash-1017) drops to $0.15 / $0.60 outside DeepSeek's peak hours. Jobs that can wait a few hours cost 50% less through the batch API at Anthropic, Google, Mistral, OpenAI. Prices from official pages, checked Oct 27, 2026. Cheapest isn't always good enough: test it on your real job first.

How much does an AI agent cost to run?

It depends on how often it runs and how much it reads. Example: a morning inbox briefing that reads about 15,000 tokens and writes 800 on 22 weekdays a month costs about $0.03 a month on Groq openai/gpt-oss-20b, and about $4.18 on Anthropic Claude Fable 5.1, at standard API prices. Use the cost calculator for your own numbers.

Is a monthly AI plan cheaper than paying per use?

If you run a few small bots, pay-per-use API prices are often a few dollars a month or less. App plans charge a flat monthly fee with usage limits, and include the app itself. Compare both before you commit: decide between a monthly AI plan and paying per use.
