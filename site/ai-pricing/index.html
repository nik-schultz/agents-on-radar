Discounts you can use

  • OpenAI: Batch API: 50% off, results within 24 hours (source, checked Oct 21, 2026)
  • OpenAI: 12-hour prompt caching (added Oct 20, 2026): keeps shared instructions cached for hours at the cached-input price; 12-hour cache writes cost 2.5x the input price (source, checked Oct 21, 2026)
  • Anthropic: Batch API: 50% off input and output. Prompt cache reads cost 0.1x the input price (0.05x on Opus/Sonnet 5.5, 0.025x on Fable 5.1); 5-minute cache writes cost 1.25x. (source, checked Oct 21, 2026)
  • Google: Batch API: 50% cost reduction (paid tier). Free tier: free input and output tokens on some models, and your content is used to improve Google's products. (source, checked Oct 21, 2026)
  • Mistral: Batch processing: 50% off. Cached input tokens: up to 90% off for repeated prompts. (source, checked Oct 21, 2026)
  • DeepSeek: Off-peak discount: prices are half outside peak hours (01:00-04:00 and 06:00-10:00 UTC on weekdays). Cache hits are far cheaper than misses. (source, checked Oct 21, 2026)
