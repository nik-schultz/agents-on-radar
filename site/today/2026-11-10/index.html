3 things that changed

  1. 1
    GGoogle🧠 model releaseYou use this

    Google's top model, Gemini 4 Carbon, is now open to paying developers and Google AI Ultra subscribers

    What it means for you: Carbon is Google's strongest model for long, multi-step jobs like big coding projects, research and security work, and it's now in the Gemini API for every paying developer at $2 in / $10 out per million tokens until Nov 30 ($4 / $20 from Dec 1), plus the Gemini app, AI Mode and Antigravity for Ultra subscribers. It uses more tokens than Gemini 4 Argon to think things through, so Google still points most everyday work to Argon; Antigravity also gets a /swarm preview that turns one prompt into a team of agents.

    Source: Google blog · Also: Gemini API pricing · 8.6K likes on X

  2. 2
    MMeta✨ featureYou use this

    Meta's Muse now has its own email address, so you can forward it emails to handle

    What it means for you: Paid Muse subscribers in the US and Canada can copy Muse on a thread or forward it a message, and it will send the replies and follow-ups for you. Because it writes on your behalf, start with low-stakes emails and check what it sends before trusting it with clients or money.

    Source: The Verge · 2.4K likes on X

    eBeBay🏢 industryYou use this

    eBay appears to be blocking AI agents like Meta's Muse from browsing its listings

    What it means for you: If your bot used to pull eBay deals into a daily digest, it may now come back empty or send you to copycat sites; eBay says it restricts agent access in some cases and already banned agents that buy without a person reviewing the order. Amazon also blocks outside agents, so check the store's own app or alerts when your bot hits a wall.

🧰 Job of the day New on the site

Teach your bot to remember what works, so it stops repeating mistakes

A bot that forgets everything between chats makes the same mistake twice. Give it a notes file it reads at the start and updates at the end, and it gets better every week. Anthropic published how it does this for Claude.

💼 Work & careerEasyWorks in: ClaudeGrok Bot

You end up with: A bot (or Claude project) that carries lessons from one session to the next. You can open the notes any time and see what it believes.

Copy today's prompt 
At the start of every job, read my notes file called [bot-notes] if it exists. When I correct you or a result turns out wrong, add one short line to the notes: what went wrong and the rule to follow next time. Mark each line 'checked' or 'guess'. At the end of each job, show me any new lines you added and ask before saving anything that includes personal or private details.

Watch out: A bad note is remembered as confidently as a good one. Anthropic's post says memory is a prediction about what will matter again, so review the notes now and then.
