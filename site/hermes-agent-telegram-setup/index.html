Hermes Agent Telegram setup: chat with your agent from your phone

Short answer: in the Hermes dashboard or desktop app, open Messaging → Telegram → Create with QR and scan it in Telegram. Or do it by hand: create a bot with @BotFather (/newbot), get your numeric user ID from @userinfobot, run hermes gateway setup, choose Telegram, paste both, then run hermes gateway and message your bot. Only the user IDs you allow can talk to it (Hermes docs).

Updated Nov 25, 2026 · By BotsDoThat

Every step comes from the official Hermes Agent docs, linked inline and checked Nov 25, 2026. Commands can change between versions; check the docs if one fails.

Why connect Hermes to Telegram

  • Your agent in your pocket. Chat with Hermes from any device; send text, voice memos (transcribed automatically), photos and files (Hermes docs).
  • Scheduled results arrive as messages. A morning brief or a price check lands in your Telegram chat instead of a terminal (Hermes docs: scheduled tasks).
  • One gateway, many apps. The same background process also serves Discord, Slack, WhatsApp, Signal, email and more (Hermes docs).

How to set up Hermes Agent on Telegram: 7 steps

  1. Make sure Hermes works first. Install Hermes and get one normal chat working on your computer before you add Telegram (the docs' quickstart order is: hermes setup, then hermes gateway setup). New to it? Start with how to install Hermes Agent.
  2. Easiest: use Create with QR. In the Hermes dashboard or desktop app, open Messaging, then Telegram, and choose Create with QR. Scan the code in Telegram: Hermes creates the bot, finds your Telegram user ID, saves both and restarts the gateway. If that works, skip to step 6.
  3. Or create the bot yourself with @BotFather. In Telegram, open @BotFather and send /newbot. Pick a display name, then a unique username that ends in bot (like my_hermes_bot). BotFather replies with a token. Treat it like a password: anyone with it controls your bot.
  4. Get your numeric Telegram user ID. Message @userinfobot and it replies with a number like 123456789. That number, not your @username, is what Hermes uses to decide who's allowed to talk to it.
  5. Run hermes gateway setup. In a terminal, run hermes gateway setup, choose Telegram, and paste the token and your user ID. (Manual option: put TELEGRAM_BOT_TOKEN and TELEGRAM_ALLOWED_USERS in ~/.hermes/.env.)
  6. Start the gateway and say hi. Run hermes gateway. The docs say the bot comes online within seconds; open your bot in Telegram and send a message. To keep it running after you close the terminal, run hermes gateway install (a background service on Mac and Linux).
  7. Pick where scheduled results land. Send /sethome in the chat you want, usually your private chat with the bot. Hermes's scheduled tasks deliver their results there.

Step 1 help: how to install Hermes Agent (Mac, Windows, Linux).

Terminal commands 
hermes gateway setup     # choose Telegram, paste token + your user ID
hermes gateway           # start it, then message your bot
hermes gateway install   # optional: keep it running in the background

Then send this to your bot as a first scheduled job. It only reads and reports:

First Telegram job for Hermes (read-only) 
Job: every morning at 7:30 AM [your time zone], send me a short brief here in Telegram.
Include: 1) today's weather for [city], 2) the 3 most important items on my list in [file or note name], 3) one reminder I set yesterday.
Use only: the web for weather and the file or note I named. Read-only.
Never: run commands that change or delete files, send messages to anyone else, buy or sign up for anything.
Ask me first: before any step that changes something or contacts anyone.
If unsure: say what you're unsure about instead of guessing.
Result: at most 8 short lines. Schedule it, then show me the schedule so I can confirm.

Using Hermes in a Telegram group

Telegram turns on privacy mode for every bot, so in a group your bot only sees /commands and replies to its own messages. To let it see the conversation, message @BotFather, send /mybots, pick your bot, then Bot Settings → Group Privacy → Turn off. Then remove the bot from the group and add it back, because Telegram remembers the old setting. Making the bot a group admin works too. To keep it quiet unless someone @mentions it, set require_mention: true under telegram in Hermes's config (Hermes docs). For a family group, see add an AI to your friends' group chat to make plans happen.

Good first jobs to run from Telegram

  • Voice notes: turn rambling voice memos into tidy notes and a to-do list.
  • Travel: turn scattered booking emails into one trip sheet that flags clashes.
  • Hobbies: let AI agents dig through public data on a hobby question (and try to prove you wrong).
  • Memory: teach your bot to remember what works, so it stops repeating mistakes.
  • Before you rely on it: back up your AI agent so you never lose its memory (and move it to a new computer).

Keep it safe: 6 rules

  1. Allow only your own user ID. The gateway denies everyone when no allowlist is set; don't switch on allow-all on a bot with terminal access (Hermes docs).
  2. Guard the bot token. Never paste it in a chat or a screenshot. If it leaks, send /revoke to @BotFather and set the new one.
  3. Keep approvals on. Risky commands should wait for your /approve; read what it wants to run first (Hermes docs; security).
  4. Treat forwarded messages and links as untrusted. Text in them can carry hidden instructions: keep hidden instructions in emails and web pages from steering your bot.
  5. Be careful in groups. Every allowed group member can steer an agent that can touch your computer. Use require_mention and allow only people you trust.
  6. Know the off switch. /stop stops the current job; hermes gateway stop stops the service.

Questions

How do I connect Hermes Agent to Telegram?

Fastest: in the Hermes dashboard or desktop app, go to Messaging, then Telegram, and use Create with QR. Manual: create a bot with @BotFather (/newbot), get your numeric user ID from @userinfobot, run hermes gateway setup, choose Telegram, paste both, then run hermes gateway and message your bot.

Why isn't my Hermes Telegram bot replying?

Check that hermes gateway is running, the token has no typo, and your numeric user ID (not your @username) is in TELEGRAM_ALLOWED_USERS. Without an allowlist the gateway denies everyone by default. In a group, see the next question.

Why does my Hermes bot work in private chat but not in a group?

Telegram bots have privacy mode on by default, so in groups they only see /commands and replies to them. Either turn it off in @BotFather (/mybots, Bot Settings, Group Privacy, Turn off) and then remove and re-add the bot to the group, or make the bot a group admin. Each sender also has to be allowed in Hermes.

Is it safe to run Hermes on Telegram?

It can be if you keep it locked down: allow only your own user ID, never post the bot token (revoke it with /revoke in BotFather if it leaks), and don't use the allow-all-users setting on a bot that can run terminal commands; the Hermes docs say that's not recommended. Keep approvals on so risky commands wait for /approve.

Can I send Hermes voice messages on Telegram?

Yes. Voice messages are transcribed automatically by the speech-to-text provider you configure. The local option uses faster-whisper on your own machine and needs no API key; Groq and OpenAI options need their keys.

Do I need to keep my computer on?

Yes, Hermes answers only while the gateway is running on that computer or server. hermes gateway install runs it as a background service on Mac and Linux. On Hermes Cloud with Team Gateway, you link your Telegram account to a shared Hermes bot instead of running your own.

Is Hermes Agent free to use on Telegram?

Hermes Agent and Telegram are free, but Hermes needs an AI model, and you pay that provider unless you run a local model. The docs note bots also need tool providers (like voice and web), and a Nous Portal subscription bundles them. To cut the model bill, see how to switch Hermes to a cheaper model.

Can other people use my Hermes bot?

Only if you allow them: add their numeric IDs to TELEGRAM_ALLOWED_USERS, or use DM pairing, where a stranger gets a one-time code and you run hermes pairing approve telegram CODE. Codes expire after an hour. Remember your bot can act on your computer, so think twice.
