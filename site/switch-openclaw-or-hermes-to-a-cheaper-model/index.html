How to switch OpenClaw or Hermes to a cheaper model

OpenClaw and Hermes Agent are free; the AI model behind them is what you pay for. Small models can cost up to 100× less than the flagship from the same company (our price table), and most everyday jobs don't need the biggest one. Here's how to switch, in each app, and when not to.

Updated Nov 4, 2026 · By BotsDoThat

OpenClaw: switch the model

  1. See what you have: openclaw models list and openclaw models status.
  2. Set a new default: openclaw models set provider/model.
  3. Or switch in chat: /model provider/model changes only this session; add -a for this agent's default or -g for the global default. /model default goes back.
  4. Add a fallback so replies keep coming when one provider is rate-limited: openclaw models fallbacks add provider/model.
  5. Cheaper helper model: agents.defaults.utilityModel sends short internal jobs (titles, summaries) to a lower-cost model.

Source: OpenClaw docs: Models. Existing chats stay pinned to their old model; start a new session to pick up the change.

Hermes Agent: switch the model

  1. Change the default: quit any chat and run hermes model. Pick a provider, sign in or paste the key, choose a model. It's saved to ~/.hermes/config.yaml and applies to new sessions.
  2. Switch inside a chat: /model model-name --provider name for this session, add --global to save it, or --once for a single turn.
  3. New provider? /model only switches between providers you've already set up; add new ones with hermes model.
  4. Gateway users (Telegram, Discord, Slack): new sessions get the new model; run hermes gateway restart to move everyone over.

Sources: Hermes docs: Configuring models, Hermes docs: LLM and model providers.

When not to go cheap

  • Agents that read email or the web and act on it. OpenClaw's docs say to avoid older or weaker models for tool-enabled agents or untrusted inputs (OpenClaw docs); smaller local models raise prompt-injection risk (OpenClaw FAQ).
  • Mid-conversation switches. Switching inside a long chat can break the prompt cache, so the next turn re-pays for the whole conversation (Hermes docs). Start a new session instead.
  • Test first. Run one real job on the new model and check the result before scheduling it.

Other ways to spend less

Start a new session for each unrelated task, keep standing instructions short, and set a spend alert: set spend limits and usage alerts on your AI accounts. More: run your bots for less, how much does it cost to run an AI agent? and is OpenClaw safe?

Questions

How do I change the model in OpenClaw?

In chat, type /model followed by provider/model (for example /model openai/gpt-5.4); add -a to make it that agent's default or -g for the global default. From the terminal, openclaw models set provider/model sets the default, and openclaw models list shows what's available.

How do I change the model in Hermes Agent?

Run hermes model in your terminal (outside a chat) to add a provider and pick a default; it's saved to ~/.hermes/config.yaml and applies to new sessions. Inside a chat, /model switches between providers you've already set up; --global also saves it, --once uses it for one turn only.

Why is OpenClaw so expensive?

Agents send their instructions, tools and the conversation so far with every message, so long chats get more expensive each turn. Start a new session for each unrelated task, and use a smaller model for routine jobs.

Will a cheaper model be less safe?

It can be. OpenClaw's docs advise against older or weaker models for tool-enabled agents or untrusted inputs, and say smaller local models raise prompt-injection risk. Keep a strong model for anything that reads email or the web and acts on it.

Does switching models mid-chat cost more?

Sometimes. Both projects warn that switching inside a long session can break the prompt cache, so the next turn pays full price for the whole conversation. For a planned change, start a new session.
