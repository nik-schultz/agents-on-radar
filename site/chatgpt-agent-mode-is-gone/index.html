ChatGPT, in plain English

ChatGPT agent mode is gone. Here's what replaced it

If you typed /agent in ChatGPT and nothing happened, it's not you. OpenAI's help page now says "ChatGPT agent is no longer available" and points to ChatGPT Work for longer, multi-step jobs, plus the cloud browser for web tasks (OpenAI Help).

Updated Nov 4, 2026 · By BotsDoThat

What ChatGPT Work is

  • An agent for longer tasks. It researches, works across your connected apps and files, and makes documents, spreadsheets, presentations and reports. You can follow along, change direction and approve important actions (release notes, July 9, 2026).
  • Chat vs Work. ChatGPT now has two modes: Chat for quick questions, Work for multi-step jobs. Codex stays for coding (OpenAI Help).
  • Scheduled Tasks. Work can run a task once, on a schedule, on a trigger, or watch for changes. How-to: put ChatGPT on a schedule: daily briefings, reminders and watchers.
  • Paid plans. Work rolled out on web and mobile to paid plans except Free and Go (release notes).

How to move your old agent tasks

  1. Open ChatGPT, switch from Chat to Work, and paste the same instructions you gave agent mode.
  2. Re-create anything that ran on a schedule as a Scheduled Task, and check the first run yourself.
  3. For jobs on websites (forms, bookings, shopping), use the cloud browser and sign in through its own sign-in screen, never by pasting a password into the chat (OpenAI Help: cloud browser).
  4. Keep "ask before sending, buying or deleting" on. See is it safe to give an AI agent your email and calendar?

Questions

Is ChatGPT agent mode gone?

Yes. OpenAI's help page now says: "ChatGPT agent is no longer available. Use ChatGPT Work for longer, multi-step tasks and finished deliverables." Browser tasks moved to the cloud browser in ChatGPT.

What replaced ChatGPT agent mode?

ChatGPT Work, introduced in OpenAI's release notes on July 9, 2026. It is an agent for longer tasks: it researches, works across connected apps and files, makes documents, spreadsheets and reports, and asks you to approve important actions. It can also run Scheduled Tasks.

Why does /agent not work in ChatGPT anymore?

Because agent mode was retired. Pick Work instead of Chat at the top of the composer (on paid plans) and describe the job.

Is ChatGPT Work free?

OpenAI's release notes say Work rolled out on web and mobile to paid plans except Free and Go.

When did agent mode stop working?

OpenAI hasn't published an exact retirement date. Its release notes introduced ChatGPT Work on July 9, 2026, and the agent help page now says agent is no longer available.
