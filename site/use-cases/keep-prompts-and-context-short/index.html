🪙 Run your bots for less

Keep your bot's prompts, tools and context short

You pay for everything the model reads on every run: your instructions, tool definitions, pasted pages and the conversation so far. Trimming those is often the easiest saving.

MediumAdded Oct 21, 2026Popularity: not measured

What the bot does

  1. Measures how many tokens each run reads (most consoles show this).
  2. Cuts instructions to the rules that matter and removes repeated examples.
  3. Turns off tools the bot doesn't need for this job.
  4. Starts fresh conversations instead of dragging a long history along, and sends only the part of a page it needs.

What you end up with

Smaller, faster runs that cost less, with the same results.

Watch out

  • Tools aren't free. Anthropic says its browser toolset adds about 6,600 input tokens per request and computer use about 4,500, before any screenshots.
  • Pages add up: Anthropic estimates an average 10 kB web page at about 2,500 tokens and a 500 kB PDF at about 125,000.
  • Don't cut safety rules (like 'ask before sending') to save tokens.
