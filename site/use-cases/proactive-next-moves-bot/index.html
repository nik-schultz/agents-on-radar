Get a bot that suggests your next moves twice a day

Instead of waiting for you to ask, this bot looks through your email, calendar and notes twice a day and comes back with two or three things worth doing next, each with a draft already written. You say yes, edit, or skip.

MediumUpdated Oct 23, 2026 · By BotsDoThat · Added Oct 23, 2026♥ 47 · ↻ 5 on X · measured Oct 27, 2026

Seen on X · Official docs

What the bot does

  1. Twice a day, on a schedule you pick, it reads what's new in the apps you connected, like Gmail, Calendar and Notion.
  2. It picks the two or three most useful next steps, like a reply you owe, a meeting to prep for, or a task that's slipping.
  3. For each one it writes a ready-to-use draft and shows them to you as short cards.
  4. It never sends or changes anything itself: you approve, edit or skip each card.
  5. If you run other bots for specific jobs, it can hand an approved task to the right one.

What you end up with

A short list of ready-to-go next steps twice a day, with the drafting already done, so you spend your time deciding instead of digging.

Copy-paste prompt

Fill in the [brackets]. Then paste it into any tool below.

Copy this prompt 
You are my next-moves assistant. Twice a day, at [9am] and [3pm], look at what's new in my [Gmail, Calendar and Notion]. Pick the 2 or 3 most useful things I should do next and, for each one, tell me in one line why it matters and write a ready-to-use draft (a reply, an agenda, a checklist). Keep everything as drafts: never send, schedule, delete or buy anything without my yes. If nothing is worth my time, say so in one line. [Optional: when I approve a task, hand it to my [writing / research / scheduling] bot.]

Setup

  1. Start with the one or two apps where most of your work lands, like email and calendar. Add notes or task apps once the suggestions feel right.
  2. Set it to run twice a day at times you actually check in, for example mid-morning and mid-afternoon.
  3. Make 'drafts only' a standing rule so nothing goes out without you.
  4. After a week, tell it which kinds of suggestions were useful and which to stop, so the list gets sharper.
  5. If you already have bots for specific jobs, list them in its instructions so it knows who to hand each kind of task to.

Watch out

  • It reads a lot of your private stuff. Connect only the apps you need and check what each connection is allowed to do.
  • Too many suggestions turns into more inbox, not less; cap it at 2 or 3 and allow 'nothing today'.
  • Keep it on drafts only, as the source post does, so a wrong guess never reaches anyone.

What this costs to run

In a chat app it runs inside your plan. If you run it as a bot on an AI API, the bill depends on how often it runs and how much it reads.
