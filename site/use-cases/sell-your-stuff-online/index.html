Write listings that sell your stuff faster

You have things to sell, but writing listings, pricing them and answering buyers is a chore.

EasyUpdated Oct 19, 2026 · By BotsDoThat · Added Oct 19, 2026

Seen on YouTube

What the bot does

  1. Take clear photos in good light.
  2. Run the prompt for each item.
  3. Check real sold prices on the marketplace before you set the price.
  4. Post, then use the saved replies for messages.

What you end up with

A clear title, honest description and price range for each item, plus ready replies for common buyer messages.

Copy-paste prompt

Fill in the [brackets]. Then paste it into any tool below.

Copy this prompt 
Help me sell this on [FACEBOOK MARKETPLACE / EBAY / ETSY / OTHER].
Item: [WHAT IT IS, BRAND, MODEL, AGE, CONDITION, FLAWS]
Photos: [UPLOAD IF YOU CAN]
Pickup/shipping: [DETAILS]

1. Write a searchable title and an honest description (mention flaws).
2. Suggest a price range and tell me how to check it against sold listings on the site.
3. Write short replies to: 'Is this still available?', lowball offers, and 'Can you hold it?'
4. List safety tips for meeting buyers and getting paid.

Watch out

  • AI price guesses can be way off. Check sold listings.
  • Be honest about flaws; it avoids returns and bad reviews.
  • Watch for buyer scams like overpayment or fake payment screenshots.

What this costs to run

In a chat app it runs inside your plan. If you run it as a bot on an AI API, the bill depends on how often it runs and how much it reads.

Questions people ask

Can AI tell what my item is from a photo?

Often yes. Ask it to identify the item and model, then confirm with any labels or serial numbers.

Which AI tools can do this?

ChatGPT, Claude, Gemini or Grok can do this today. Paste the copy-paste prompt on this page into any of them and fill in the [brackets].

How hard is it to set up?

It's rated Easy. Start with the steps under “What the bot does”.

How much time can it save?

Poshmark says its Smart List AI, which drafts a listing from one photo, cut listing times by an average of 48% in beta testing. Source: Digital Commerce 360: Poshmark introduces generative AI tool for its product listings (Feb 4, 2025).

What should I watch out for?
