Hand a clunky web form to an agent that uses the computer

Some software you only touch once a year. A computer-use agent can click through it for you, from a login you control, while you watch.

EasyUpdated Oct 21, 2026 · By BotsDoThat · Added Oct 21, 2026♥ 3 · ↻ 0 on X · measured Oct 23, 2026

What the bot does

  1. Opens the site or app in its own browser.
  2. Asks you to sign in yourself (or uses a password manager you set up).
  3. Fills in the form from the details you gave it.
  4. Stops before the final submit and shows you what it entered.

What you end up with

The form filled in correctly without you learning the software, ready for your final click.

Copy-paste prompt

Fill in the [brackets]. Then paste it into any tool below.

Copy this prompt 
Open [website or app] and fill in the [form name] for me. Here are the details: [list everything it needs]. When you reach a login, stop and let me sign in. If any field is unclear, ask me instead of guessing. Stop before the final Submit button and show me a summary of everything you entered.

Tools that can do it today

  • agentChatGPT Work (cloud browser)Cloud browser agentPaid ChatGPT plans only (not Free or Go); rolling out
  • agentGrok Bot (personal agents)Included with paid individual Cursor plans and Cursor Teams; or link SuperGrok, SuperGrok Plus or SuperGrok Heavy; or a self-serve Grok Business seat
  • agentClaude CoworkPaid Claude plans only (Pro, Max, Team, Enterprise)

Plans and limits change; check each tool's page.

Watch out

  • Sign in yourself or use a password manager. Don't paste passwords into the chat.
  • Always check the summary before submitting. Agents can misread a page.

What this costs to run

In a chat app it runs inside your plan. If you run it as a bot on an AI API, the bill depends on how often it runs and how much it reads.
