Use a small model for simple jobs and save the big one for hard ones

Most bot jobs (sorting email, summarizing, checking a page) don't need the most powerful model. The small models cost a fraction as much, so route easy work to them and only send hard problems up.

MediumAdded Oct 21, 2026Popularity: not measured

What the bot does

  1. Sends routine work (summaries, sorting, yes/no checks) to a small, cheap model.
  2. Sends hard work (tricky reasoning, long documents, important drafts) to a bigger model.
  3. Optionally lets the small model decide: if it isn't sure, it hands the job up.
  4. Logs which model handled what, so you can see where the money goes.

What you end up with

The same results on everyday jobs for a fraction of the cost, with the expensive model kept for the jobs that need it.
