Put a small team of agents on one project, each with its own job

Instead of one chatbot doing everything, give separate agents separate roles (one researches, one builds) and let them hand work to each other in a shared conversation you can watch.

AdvancedUpdated Oct 21, 2026 · By BotsDoThat · Added Oct 21, 2026♥ 198 · ↻ 35 on X · measured Oct 29, 2026

Seen on X · YouTube ×2 · GitHub

What the bot does

  1. You set up two or more agents, each with one role, like "market research" and "website builder".
  2. The first agent does its part and shares what it found.
  3. The next agent picks that up and builds on it.
  4. You and your partner watch in the same group conversation and step in when needed.

What you end up with

One finished piece of work (in the source, a simple website) built from a research step and a build step, with every hand-off visible.

Copy-paste prompt

Fill in the [brackets]. Then paste it into any tool below.

Copy this prompt 
We're a team of two agents. Agent 1 (Researcher): research [topic] and write a one-page brief with sources. Agent 2 (Builder): when the brief is ready, use it to build [deliverable]. Post each hand-off in this chat so I can see it. Ask me before publishing, sending or buying anything.

Watch out

  • The source post promotes a specific product (Teamily); treat it as a pitch, not an independent review.
  • Keep a plain log of which agent decided what, so you can tell where a mistake came from.
  • Keep business and personal agents separate so private details don't flow into the wrong place.

What this costs to run

In a chat app it runs inside your plan. If you run it as a bot on an AI API, the bill depends on how often it runs and how much it reads.
