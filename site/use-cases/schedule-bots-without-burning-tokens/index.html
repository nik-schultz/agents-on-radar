Stop always-on bots from burning tokens: run them less often, or on demand

Every scheduled run costs tokens, even when nothing has changed. Match the schedule to how often the thing really changes, and switch fun-but-idle bots to run only when you ask.

EasyAdded Oct 21, 2026♥ 11 · ↻ 1 on X · measured Oct 23, 2026

What the bot does

  1. Lists every scheduled bot and how often it runs.
  2. Asks how often the thing it watches really changes (daily, weekly, rarely).
  3. Lowers the schedule to match, or switches the bot to on-demand.
  4. Makes each run cheap when nothing changed: a quick check first, a full report only if something did.

What you end up with

The same alerts and reports with far fewer paid runs.

Copy this prompt 
Here are my scheduled bots: [name, what it does, how often it runs]. For each one, suggest the least frequent schedule that still catches what matters, or say if it should run only when I ask. For watchers, rewrite the instructions so each run first checks whether anything changed and stops with a one-line 'no change' if nothing did.
