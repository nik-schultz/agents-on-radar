Teach a bot to write emails that sound like you

Have the bot read your last 50 sent emails, write a style guide, then use it for every draft.

EasyAdded Oct 20, 2026Popularity: not measured

What the bot does

  1. Reads a sample of your sent emails.
  2. Writes a short style guide: tone, length, greetings, sign-offs.
  3. Saves it as a reusable skill.
  4. Uses it whenever it drafts for you.

What you end up with

Drafts that sound like you, so you edit less.

Copy-paste prompt

Fill in the [brackets]. Then paste it into any tool below.

Copy this prompt 
Read through the last 50 emails I wrote and turn them into a style guide for how I write emails. Turn that into a skill that gets used every time I ask you to draft an email. Call the skill 'ghostwriter'. Drafts only; never send.
