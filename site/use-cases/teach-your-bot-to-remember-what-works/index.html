Teach your bot to remember what works, so it stops repeating mistakes

A bot that forgets everything between chats makes the same mistake twice. Give it a notes file it reads at the start and updates at the end, and it gets better every week. Anthropic published how it does this for Claude.

EasyUpdated Nov 9, 2026 · By BotsDoThat · Added Nov 9, 2026▲ 186 points on Hacker News · measured Nov 9, 2026

Seen on Hacker News ×2 · Official docs

What the bot does

  1. Starts each job by reading a short notes file of rules and facts it has already checked.
  2. Does the job, and when you correct it, writes the fix down as a one-line rule.
  3. Now and then tidies the notes: merges duplicates and marks what is verified and what is still a guess.
  4. Shows you the notes so you can edit or delete anything.

What you end up with

A bot (or Claude project) that carries lessons from one session to the next. You can open the notes any time and see what it believes.

Copy-paste prompt

Fill in the [brackets]. Then paste it into any tool below.

Copy this prompt 
At the start of every job, read my notes file called [bot-notes] if it exists. When I correct you or a result turns out wrong, add one short line to the notes: what went wrong and the rule to follow next time. Mark each line 'checked' or 'guess'. At the end of each job, show me any new lines you added and ask before saving anything that includes personal or private details.

Setup

  1. Pick where the notes live: a Project in Claude with a notes document, or a note/file your bot can read and edit.
  2. In Claude, open Settings and check that memory and 'Search and reference chats' are on (or off, if you prefer privacy). Use an incognito chat for anything you do not want remembered.
  3. Paste the prompt above as the bot's standing instructions.
  4. After a week, open the notes and delete anything wrong or too personal.

Watch out

  • A bad note is remembered as confidently as a good one. Anthropic's post says memory is a prediction about what will matter again, so review the notes now and then.
  • Do not let the bot save passwords, account numbers or other people's private details into notes.
  • Memory features differ by plan and app; check the Claude Help Center article for what your plan includes.

What this costs to run

In a chat app it runs inside your plan. If you run it as a bot on an AI API, the bill depends on how often it runs and how much it reads.
