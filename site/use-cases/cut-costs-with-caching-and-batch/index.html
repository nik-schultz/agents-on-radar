Cut your AI bill with prompt caching and batch discounts

If your bot sends the same long instructions every time, caching makes the repeat part much cheaper. If results can wait a few hours, batch processing halves the price at several providers.

AdvancedAdded Oct 21, 2026Popularity: not measured

What the bot does

  1. Puts the parts that never change (instructions, examples, reference docs) at the start of the prompt so they can be cached.
  2. Re-uses that cached part on every run instead of paying full price for it.
  3. Collects jobs that aren't urgent (nightly summaries, weekly reports) into one batch.
  4. Sends the batch at the discounted rate and picks up the results later.

What you end up with

The same bot output, with repeated instructions billed at a fraction of the input price and non-urgent work at half price.

Watch out

  • Caching only pays if the same prefix is re-used soon: Anthropic's 5-minute cache write costs 1.25x, and a read costs 0.1x the input price on most models.
  • Batch jobs aren't instant. OpenAI says each batch completes within 24 hours.
  • Not every model supports batch; check the provider's model page.
