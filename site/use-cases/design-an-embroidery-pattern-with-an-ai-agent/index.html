Design an embroidery pattern by telling an AI agent what to stitch

ZigZag is a free, open-source embroidery editor for Mac and Windows with a built-in connection for AI agents. You describe a patch or monogram, the agent draws it in the editor while you watch, checks a stitch preview, and exports a file your embroidery machine can sew.

AdvancedUpdated Nov 13, 2026 · By BotsDoThat · Added Nov 13, 2026▲ 689 points on Hacker News · measured Nov 13, 2026

Seen on Hacker News · GitHub · Official docs

What the bot does

  1. Connects to the ZigZag editor on your computer (it only listens on your own machine).
  2. Draws shapes and lettering from your description, or places and traces artwork you give it.
  3. Picks stitch types (fill, satin, running stitch and more) and sets the fabric and hoop size.
  4. Renders a picture of the stitches and runs the editor's design check so it can fix problems before you sew.
  5. Exports a PES, DST, EXP, JEF or VP3 file, or sends the design to a Brother Skitch over Bluetooth when you say so.

What you end up with

A finished embroidery file for your machine, plus the design open in the editor so you can tweak any stitch yourself. Every agent step is one Undo.

Copy-paste prompt

Fill in the [brackets]. Then paste it into any tool below.

Copy this prompt 
In ZigZag, make a [size, e.g. 70 mm round] embroidered patch for [fabric, e.g. a denim jacket] that says '[text]' with [simple picture, e.g. a small mountain]. Use [number] thread colours at most, satin for the border and lettering, fill for the shapes. Render a stitch preview and run the design check, then show me before you change anything else. Don't export or send anything to my machine until I say yes.

Setup

  1. Download ZigZag for Mac or Windows from zigzag.diy (free, Apache 2.0) and open it.
  2. Click MCP in the bottom-right status bar. It shows the address and copy buttons to connect Claude Code or Claude Desktop.
  3. For Claude Code, run: claude mcp add --transport http zigzag http://127.0.0.1:7878/mcp. Or use ZigZag's built-in Ask Agent panel with a Claude Code or Codex sign-in you already have.
  4. Start with a simple design (a name or a small icon), check the stitch preview, then export the file type your machine uses.
  5. Sew a test on scrap fabric before the real garment.

Watch out

  • It's a new hobby project (version 0.1.x). Expect rough edges and keep backups of designs you care about.
  • Only the Brother Skitch PP1 can receive designs over Bluetooth, and you must close Brother's Artspira app first. The README advises against Skitch firmware updates.
  • On Windows, SmartScreen warns the first time because the app isn't Microsoft-signed (the README explains More info > Run anyway).
  • Agents can make odd stitch choices. Always look at the stitch preview, and test-sew, before using expensive fabric.
  • Only stitch artwork you have the right to use.

What this costs to run

In a chat app it runs inside your plan. If you run it as a bot on an AI API, the bill depends on how often it runs and how much it reads.
